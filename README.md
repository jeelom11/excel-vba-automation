# N3 Expected Value Project

This repository contains a minimal, testable structure for an N3 expected value calculator.

## Project layout

- `app.py`: Streamlit user interface.
- `n3/`: Core math and simulation utilities.
- `tests/`: Pytest suite.

## Getting started

1. Create a virtual environment (optional but recommended).
2. Install dependencies:

```bash
pip install -r requirements.txt
```

3. Run tests:

```bash
pytest -q
```

4. Launch the UI:

```bash
streamlit run app.py
```
